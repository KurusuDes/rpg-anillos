Política de privacidad

Inflation! Coop Lite-RPG · actualizada el 28 de octubre de 2026 · English below

Inflation! Coop Lite-RPG es un juego gratuito que se juega en el navegador o con la app de Android, que abre la misma página. No tiene cuentas, anuncios, compras dentro del juego ni herramientas de analítica.

Qué datos se usan

  • Nombre de jugador. Usted lo escribe al crear una sala o unirse a ella. Solo lo ven los demás jugadores de esa sala. No se guarda en ningún servidor del juego.
  • Partida multijugador. Para conectar a los jugadores, el juego usa el servidor público de señalización de PeerJS (peerjs.com), que pone en contacto a los navegadores por un código de sala. Después, los navegadores se conectan directamente entre sí (WebRTC). En esa conexión, cada jugador puede ver la dirección IP de los demás, como en cualquier conexión directa por internet.
  • Partida guardada y registro. Cuando usted elige "Guardar partida" o "Exportar registro", el juego descarga un archivo en su dispositivo. No se envía a ningún sitio.
  • Archivos del juego. El dispositivo guarda una copia de las imágenes y el código del juego para que cargue más rápido. No contiene datos personales.

Servicios de terceros

  • GitHub Pages aloja el juego. GitHub puede registrar datos técnicos de las visitas, como la dirección IP (declaración de privacidad de GitHub).
  • Google Fonts sirve las fuentes de la interfaz (política de privacidad de Google).
  • PeerJS conecta a los jugadores en las partidas multijugador (peerjs.com).

Lo que no hacemos

No vendemos ni compartimos datos, no mostramos publicidad, no creamos perfiles y no pedimos permisos del dispositivo (ubicación, cámara, micrófono, contactos).

Contacto

Para cualquier pregunta sobre privacidad, abra una consulta en github.com/KurusuDes/rpg-anillos/issues.

Privacy policy

Inflation! Coop Lite-RPG · updated October 28, 2026

Inflation! Coop Lite-RPG is a free game played in the browser or with the Android app, which opens the same page. It has no accounts, ads, in-game purchases or analytics tools.

What data is used

  • Player name. You type it when you create or join a room. Only the other players in that room see it. It is not stored on any game server.
  • Multiplayer games. To connect players, the game uses the public PeerJS signaling server (peerjs.com), which introduces browsers to each other by a room code. The browsers then connect directly (WebRTC). In that connection, each player can see the others' IP addresses, as in any direct connection over the internet.
  • Saved game and log. When you choose "Save game" or "Export log", the game downloads a file to your device. It is not sent anywhere.
  • Game files. Your device keeps a copy of the game's images and code so it loads faster. It contains no personal data.

Third-party services

  • GitHub Pages hosts the game. GitHub may log technical visit data such as your IP address (GitHub privacy statement).
  • Google Fonts serves the interface fonts (Google privacy policy).
  • PeerJS connects players in multiplayer games (peerjs.com).

What we don't do

We don't sell or share data, show ads, build profiles, or ask for device permissions (location, camera, microphone, contacts).

Contact

For any privacy question, open an issue at github.com/KurusuDes/rpg-anillos/issues.
